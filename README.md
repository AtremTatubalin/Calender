# Calendar / Запись на занятия

Минимальный прототип веб-приложения для записи на занятия.

## Что уже реализовано

- Регистрация пользователя: имя, фамилия, адрес, телефон, пароль.
- Вход по телефону + паролю.
- Создание админ-аккаунта на странице регистрации через галочку и секретный код.
- Просмотр свободных слотов.
- Запись в свободный слот.
- Отмена своей записи.
- Удаление своей записи.
- Для администратора:
  - просмотр занятых слотов;
  - просмотр заблокированных слотов;
  - блокировка/разблокировка слотов;
  - добавление нового слота;
  - просмотр и удаление зарегистрированных пользователей.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export FLASK_SECRET_KEY='replace-me'
export ADMIN_SECRET_CODE='my-secret-admin-code'
python app.py
```

Сайт будет доступен на `http://localhost:5000`.

## Технические заметки

- База данных: `SQLite` (`app.db`), создаётся автоматически при первом запуске.
- По умолчанию автоматически создаются слоты на 14 дней вперёд с временем `10:00`, `12:00`, `14:00`.
- Endpoint `POST /delete/<slot_id>` удаляет запись пользователя из его списка и освобождает слот (слот не удаляется из расписания).
