Как установить приложение на телефон

Сайт поддерживает формат PWA (Progressive Web App). Его можно установить как обычное приложение на Android и iPhone.

Android (Chrome)

  1. Откройте сайт в Chrome.
  2. Нажмите меню браузера (⋮).
  3. Выберите «Установить приложение» или «Добавить на главный экран».
  4. Подтвердите установку.

iPhone (Safari)

  1. Откройте сайт в Safari.
  2. Нажмите кнопку «Поделиться».
  3. Выберите «На экран Домой».
  4. Подтвердите добавление.

Важно

  • Для корректной установки сайт должен открываться по HTTPS.
  • После установки приложение запускается с иконки на домашнем экране.
  • Если кнопки установки не видно — обновите страницу и попробуйте снова.
